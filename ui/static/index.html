    System Architecture

    Dual-Process Interruptible Agent Architecture

    Engineered for Samsung PRISM Theme 05. The system decouples immediate reflexive conversational feedback from asynchronous tool execution and perception.

    Core Design Principles

    Zero-Latency Barge-In
    Every user utterance or interruption is processed in under 5 milliseconds. The fast path immediately updates internal slot hypotheses, halts outdated TTS speech, issues contextual filler acknowledgments, and halts obsolete background work without freezing the event consumer.
    Epoch-Guarded Invalidation
    Each interruption increments a monotonic epoch counter. Outbound tool calls and perception tasks carry their originating epoch; any completion arriving with a superseded epoch is immediately discarded, preventing race conditions.
    Uncertainty-Aware ASR
    When speech transcription exhibits low confidence or multiple phonetically plausible options (e.g. Austin vs Boston), the agent generates a focused clarification request ("Did you say Austin or Boston?") rather than guessing blindly.
    Zero-Shot Schema Tools
    Tools are dynamically ranked by semantic overlap with function declarations, parameter schemas, and type definitions. Required arguments are intelligently synthesized directly from user requests.
    Multi-Modal Visual Grounding
    Multi-angle OCR is coupled with zero-shot CLIP embeddings on center-cropped frames. High-confidence visual features guide tool invocation, while ambiguous frames trigger explicit user confirmation.
    Deterministic Safety Ledger
    Fillers are capped at an evaluation budget of 3 per turn. State-modifying operations are indexed in an idempotency register to guarantee at-most-once execution under all network conditions.
